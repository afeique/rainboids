### CONFIRMED ISSUE — rate-limit can be exceeded (escalation + exponent compound)
- The B4 trace shows **D_hp moving +25.4%/wave** (waves 3–6) for the Synergy God, **breaching the documented "≤12%/wave" guard** (Balance §8 / director header).
- **Root cause (verified in isolation):** within a single `updateDifficulty()`, the D_hp exponent step is rate-limited to +12% (`D_hp·Po^0.5` clamped to `×1.12`), and THEN the **escalation** block (`clearedFullHp && clearTimeFrac<0.6`) applies a SECOND, independently rate-limited `×(1+maxStep)` = another +12% on top. Net ≈ **+25.4%/wave**. Reproduced directly: cold-start→`D_hp 1.0 → 1.2544` in one wave when escalation fires. The same can affect the D_thr mastery+escalation path.
- **Impact:** for a stomping build the offense outlet ramps roughly twice as fast as the spec intends — it reaches the D_hp 3.0 ceiling in ~5 waves instead of ~10. Whether that's desirable (faster catch-up) or a bug (defeats the "sub-perceptual, no rubber-band" intent) is a tuning call — flagged, not "fixed."

### Oscillation / stability (B5) — THRASHES under adversarial wobble

Balance §9 claims "EMA + deadband prevent thrash" — **true for noisy-but-centered inputs, false for a true square-wave**.
